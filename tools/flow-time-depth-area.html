About this calculator

System flow rate (Q), time of application (t), area irrigated (A), and depth applied (d) are related by (assuming Q is constant over the application time):

Q × t = A × d

Pick which quantity you want to solve for, enter the other three, and choose the unit you'd like the answer reported in. This is the same relationship used to size a system's run time, check a design flow rate, or back-calculate area from a known application depth and time.
