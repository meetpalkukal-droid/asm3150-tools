About this calculator

The scheduling coefficient (SC) is simply the inverse of DU. If DU = 0.80, SC = 1.25 — the system needs to run 25% longer than a perfectly uniform system would, so that the driest spots (the low quarter) still receive the target depth.

dLQ = DU × dz   —   SC = dz / dLQ = 1 / DU   —   actual time = ideal time × SC

Textbook Example 5.4: A sod farm system has DU=0.80, dz=1.5 in, and ran for 5 h. SC = 1/0.80 = 1.25, dLQ=1.2 in. With perfect uniformity, the same result would have taken 5 h ÷ 1.25 = 4 h. Click "Load textbook Example 5.4" above (solving for the perfect-uniformity time) to see it worked through.
