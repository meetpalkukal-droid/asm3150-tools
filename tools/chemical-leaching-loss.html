About this calculator

Deep percolation — and whatever is dissolved in it — comes from two sources: nonuniform infiltration (Vdp1) and over-application beyond the soil water deficit (Vdp2). F1 (interpolated from Table 5.1) is an empirical factor relating CU to the fraction of infiltrated water lost to nonuniformity, assuming a 90%-adequacy, normally distributed application.

Vdp1 = dzA(1−F1)   —   Vdp2 = 0.95A(dLQ−SWD) if dLQ>SWD, else 0

Vdp = Vdp1+Vdp2   —   dp = Vdp/A   —   Cl = 0.226 × C × dp

Table 5.1 only tabulates F1 for CU between 70 and 98. Outside that range this tool will warn rather than guess by extrapolating.

Textbook Example 5.5: Using Example 5.1's field (dz=2.0 in, CU=84% → F1=0.71, dLQ=1.5 in) with SWD=1.2 in and C=20 ppm: Vdp1=0.58 ac-in, Vdp2=0.29 ac-in, Vdp=0.87 ac-in, dp=0.87 in, Cl=3.9 lb/ac. Click "Load textbook Example 5.5" above to see it worked through.
